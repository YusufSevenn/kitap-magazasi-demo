📚 KitapEvi Online - Kitap Takip ve Satış Sistemi
Bu proje, modern bir kitap mağazasının ihtiyaç duyabileceği envanter yönetimi ve müşteri satış simülasyonunu gerçekleştirmek amacıyla geliştirilmiş Full-Stack bir web uygulamasıdır.

🚀 Kullanılan Teknolojiler
Frontend

React.js: Bileşen tabanlı modern arayüz mimarisi.

Tailwind CSS: Modern ve duyarlı (responsive) tasarım bileşenleri.

Axios: Backend API servisleri ile asenkron veri iletişimi.

React Router Dom: Dinamik sayfa yönlendirmeleri ve navigasyon yönetimi.

Backend

NestJS: Ölçeklenebilir, modüler ve TypeScript tabanlı sunucu mimarisi.

TypeORM: Veritabanı yönetimini kolaylaştıran gelişmiş ORM yapısı.

sqlite: Demo için basit veritabanı.

✨ Temel Özellikler
📖 Kullanıcı Arayüzü

Dinamik Kitap Listeleme: Mağazadaki kitapların anlık olarak ana sayfada görüntülenmesi.

Satın Alma Simülasyonu: Kitapların satış adetlerini güncelleyen interaktif yapı.

⚙️ Yönetim (Admin) Paneli

Envanter Yönetimi: Yeni kitap ekleme, mevcut kitapları silme ve güncelleme işlemleri.

İstatistik Takibi: Satılan ürünlerin admin üzerinden kontrolü.

Veritabanı Sıfırlama: Tek tuşla veritabanını başlangıç (seed) verilerine döndürerek sistemi taze tutma özelliği.
